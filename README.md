# Проверка сделок Битрикс24

Скрипт проверяет сделки в отчёте. В Битриксе **ничего не меняет** — только пишет, что исправить.

## Запуск

1. Один раз установите Node.js LTS: https://nodejs.org  
2. В папке проекта:

```bash
node start.js
```

3. Залогиньтесь в Битрикс → вставьте ссылку на отчёт → Enter  

Результат: в терминале и в `results/check_latest.csv` (Excel).

Зависимости и браузер ставятся **сами при первом запуске**, дальше не качаются.

## Что проверяет

Месяц завершения, счёт заказчику (кроме сделок НАЛ…/QR…), суммы из предоплаты/постоплаты/списания и графы затрат (порядок сумм не важен).

Настройки полей — `config.js`.
